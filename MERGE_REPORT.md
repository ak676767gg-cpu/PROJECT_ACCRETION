# Combined ACCRETION project

Inputs: the current accretion-expedition-update.zip (2.4.0) and the attached accretion-improved (1).zip (its separate 2.3.0 branch). Both originals were left untouched.

The shared 2.2 project was used as the merge base. Shared files and code are included once; unique changes from both inputs are retained. Repeated syntactic lines such as closing braces were preserved where the program needs them. No unrelated features, redesign, assets, dependencies or additional gameplay retuning were introduced.

The current version supplies Expedition systems, planetary composition/climate/resonance, separate sandbox state, replay/photo modes and publication-review pages. The attachment supplies shape-based companion passives, Life Lab tabs and egg descriptions, additional records/achievements, rival-personality changes, reactive ambience, forecast/apsis/minimap improvements, stellar pacing values and bounded caches/pools.

Conflicting integration lines were combined rather than keeping two definitions or two loops. The current version number, current presentation and publication gates remain. Existing evolved creature visuals and photo label controls coexist with companion passives and the label setting. Shared saves retain both data sets, including sandbox isolation for the added lifetime records.

Two compatibility adjustments were necessary to retain existing behavior: exact scanner-distance checks keep the attachment's larger spatial-hash cells from enlarging either life scanner, and nickname visibility respects the merged Life Lab tabs. Offline diagnostics use the combined menu markup so all merged controls exist. No original resource costs, wheel probabilities, evolution gates or black-hole accretion values were retuned beyond the changes already supplied in the attachment.
